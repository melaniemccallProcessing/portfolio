Order Fulfillment & Inventory Automation App

Stack: Node.js · Shopify Admin API · XML APIs · Axios · Nodemailer · Heroku Scheduler

Year: 2019 (Refactored 2025)

View Project on Github

Overview

I built an automation system that connects a Shopify store to a legacy third-party dropshipper that had no native Shopify integration. The system handles order submission, shipment tracking, partial cancellations, refunds, and inventory synchronization — without manual intervention. This project powered a real e-commerce business and ran on a schedule, quietly doing its job while everyone else slept.

The Problem

The business relied on a dropshipper that only supported XML-based APIs and offered no real-time webhooks. Orders were being processed manually, inventory frequently went out of sync, and partial shipments caused confusion for both customers and staff. In short:

  • Orders needed to flow from Shopify → vendor automatically
  • Inventory needed to stay accurate across thousands of SKUs
  • Partial shipments and cancellations had to be handled safely
  • Customers needed clear communication when items were unavailable
  • Doing this manually did not scale.

Constraints & Challenges

This was not a clean, modern REST-only environment. Key constraints included:

  • A legacy XML API with inconsistent responses
  • No real-time fulfillment notifications
  • Partial shipments requiring refunds and custom logic
  • Payment capture timing (authorized vs paid orders)
  • Avoiding double fulfillment or incorrect refunds
  • Running scheduled jobs reliably without human oversight
The solution had to be defensive, predictable, and idempotent.

The Solution

I designed the system as three independent processes:

  1. Order Webhook Handler:
    When a customer places an order:
    • Shopify sends a webhook
    • The order is transformed into XML
    • The order is sent to the dropshipper
    • The Shopify order is tagged with a vendor order ID for tracking
  2. Order Status Worker (Hourly):
    • Polls the dropshipper for shipment status
    • Automatically fulfills shipped orders in Shopify
    • Captures payment when appropriate
    • Handles partial shipments with refunds and customer notifications
    • Emails internal summaries for visibility
  3. Inventory Sync Worker (Hourly)
    • Downloads the vendor's full inventory feed
    • Updates product availability and tags in Shopify
    • Creates new products when appropriate
    • Unpublishes discontinued items
    • Maintains Shopify as a clean storefront backed by vendor data
    Each process could run independently and recover gracefully from failures.

Key Technical Decisions

  • Scheduled workers instead of real-time polling to accommodate a vendor without webhooks
  • Order tagging to reliably link Shopify orders to vendor records
  • Source-of-truth inventory model, treating the vendor feed as authoritative
  • Email summaries instead of dashboards for lightweight monitoring and updates to business owners
  • Fail-safe defaults for partial shipments and cancellations

Results & Impact

  • Eliminated manual order processing
  • Reduced inventory mismatches and overselling
  • Automated refunds and customer notifications
  • Allowed the business to scale without additional staff
  • System ran unattended on a schedule with minimal maintenance
