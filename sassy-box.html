WordPress + BigCommerce Subscription E-Commerce Platform

Year: 2019-2023

Overview

I served as the webmaster and e-commerce developer for an online adult retail company, Sassy Box, offering both individual product sales and monthly subscription box services. The platform ran on a hybrid architecture: WordPress frontend connected to a BigCommerce backend for product, order, and customer management. My role covered redesigning the site UI, integrating BigCommerce product data into WordPress, managing plugins and subscription tools, and keeping the storefront secure, functional, and conversion-focused.

Role and Responsibilities

  • Lead developer and maintenance owner
  • WordPress theme customization & UI redesign
  • BigCommerce integration setup and data syncing
  • Subscription product configuration + recurring billing support
  • SEO + PageSpeed improvements
  • Bug fixes & ongoing content updates
  • Managed promotional campaigns and landing pages
  • System troubleshooting + plugin governance

Platform Architecture

  • Frontend: WordPress
  • Commerce Engine: BigCommerce
  • Theme Tools: Elementor / WPBakery / Custom CSS
  • Checkout + Subscriptions: WooCommerce Subscription framework
  • Customer Profiles & Order Data: Synced from BigCommerce to WordPress
  • Hosting + Security: WP plugin management + caching

Key Integrations

  • WP BigCommerce Plugin (official connector)
  • WooCommerce Subscriptions
  • Klaviyo
  • Stripe and PayPal checkout plugins
  • Yoast SEO
  • Advanced Custom Fields
  • Google Analytics plugin
  • PirateShip
  • Judge.me Product review plugin

Key Achievements

  • Fully redesigned the WordPress frontend, improving navigation clarity, branding cohesion, and product discovery.
  • Integrated the WordPress site with BigCommerce APIs to pull product details, inventory, pricing, and order routing.
  • Built subscription plan workflows and automated recurring billing logic for monthly box memberships.
  • Reduced manual inventory sync work by connecting WordPress to BigCommerce product data.
  • Implemented SEO enhancements that increased organic product visibility.
  • Managed ongoing storefront maintenance, plugin updates, and bug remediation.

Results & Impact

  • Eliminated manual order processing
  • Reduced inventory mismatches and overselling
  • Automated refunds and customer notifications
  • Allowed the business to scale without additional staff
